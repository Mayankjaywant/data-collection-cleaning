# YUVA Intern – Week 2
## Data Collection Strategy and Cleaning

### Project focus
Data-driven study of barriers to accessing digital public services in rural communities.

### Contents
- `Week_2_Data_Collection_Strategy_and_Cleaning_Mayank.docx` – complete Week 2 report
- `data/raw/sample_digital_public_services.csv` – synthetic demonstration data only
- `data/processed/README.md` – processed-data guidance
- `src/clean_data.py` – basic reproducible cleaning and validation example
- `requirements.txt` – Python dependencies
- `LICENSE.txt` – use note

### Important
The sample CSV is synthetic and must not be represented as real citizen data. Do not upload personally identifiable information to a public GitHub repository.

### Suggested workflow
1. Review the Week 2 report.
2. Replace the synthetic sample only with properly sourced and privacy-reviewed data when the next stage requires it.
3. Record source metadata and cleaning decisions.
4. Run the Python script.
5. Review validation output before analysis.

### Public data sources to consider
- Open Government Data Platform India: https://www.data.gov.in/
- Census of India: https://censusindia.gov.in/
- TRAI: https://www.trai.gov.in/

Always check the current dataset metadata and usage terms before downloading or redistributing data.
